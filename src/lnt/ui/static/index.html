Захват

Ручной запуск

Для анализа CH2 должен видеть сеть 50 Гц: подключите трансформатор 230:6 к CH2.

Трансформатор: частота, RMS, THD и гармоники сети. Пробник на вторичке, переключатель в 10x, один канал.
Без CH2 метрики фазовой привязки (P_async/P_sync, частота сети) будут «н/д»; спектр и пики считаются полностью.

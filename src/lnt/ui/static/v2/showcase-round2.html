Четыре варианта на общем языке

Один плотный срез продукта — каталог, спектр A/B, метрики, форма захвата, ошибка — в четырёх скелетах: воркбенч, компактная студия, верхние вкладки, карточный дашборд. Язык общий: шкала, типографика и геометрия фиксированы; различаются только компоновка и плотность.

  • V1 — Классический воркбенч трёхпанельный docked-воркспейс: каталог слева, спектр в центре, инспектор справа
  • V2 — Компактная студия скелет V1 с высокой плотностью данных: 12px таблицы, строки 28px, инспектор 260px
  • V3 — Верхние вкладки навигация таб-баром в шапке: каталог слева 320px, анализ справа во всю ширину
  • V4 — Карточный дашборд сайдбар как в V1, центр — сетка карточек с рамками-хейрлайнами без теней
  • V5 — Аналитическая станция эволюция V3: полоса контекста сессии, весь срез без прокрутки, маркеры пиков на спектре
  • V6 — Сравнение единица работы — пара сессий: полоса А—Б, дельта пиков числом, захват командной строкой

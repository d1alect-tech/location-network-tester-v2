Исходники Windows-релиза LNT 0.1.2
=================================

Публичный релиз распространяется под GPL-3.0-only. На одной странице GitHub
Release публикуются четыре актива:
LNT-0.1.2-win64.zip
LNT-0.1.2-win64.zip.sha256
LNT-0.1.2-corresponding-source.zip
LNT-0.1.2-corresponding-source.zip.sha256

https://github.com/d1alect-tech/location-network-tester-v2/releases/tag/v0.1.2

Скачайте оба архива и сверьте SHA-256 по примечаниям к релизу и двум файлам
.sha256. Документация не содержит хеши архивов до их сборки и публикации.

Corresponding Source включает код и материалы сборки для версии 0.1.2, в том
числе Hantek6022API из точного коммита
e65d52b0f2536e56eaadbb555e5d7b756409c36e. Аппаратная часть LNT рассчитана
только на Hantek 6022BE. Zadig и WinUSB распространяются отдельно и в активы
LNT не входят.

Распакуйте архив исходников. SHA256SUMS проверяет каждый указанный файл, в том
числе файл внутри каталога зависимостей или результатов сборки. При поиске
лишних файлов SourceArchive пропускает только известные каталоги зависимостей,
результатов сборки и кэши Python.

Подготовьте зафиксированные зависимости, соберите frontend и передайте локальный
репозиторий Hantek в скрипт сборки:

    uv sync --locked --python 3.12 --all-extras --project project
    npm --prefix project/frontend ci
    npm --prefix project/frontend run build
    powershell -File project/packaging/build.ps1 -Clean -Evidence evidence -SourceArchive -HantekSource sources/hantek/hantek.git

Эти команды устанавливают зафиксированные зависимости и собирают frontend. Они
не собирают из исходников все вложенные нативные компоненты. Их исходники,
версии и пути сборки записаны в SOURCE-MANIFEST.json.

Для выпуска принято свидетельство sanitized-reference-host-verified с
типизированным состоянием device_absent. Оно не подтверждает проверку на
чистой машине или работу с физическим осциллографом.

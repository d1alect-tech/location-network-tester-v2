# ADR-0009: Витрина V6 «Сравнение» — финальное направление UI раунда 2

## Status

Принято владельцем продукта 2026-08-30 как финальный дизайн раунда 2.
Витрина — эталон дизайна и тезисов; перенос в боевой интерфейс (`#/inspect`)
отложен на последующую работу и выполняется по этому документу.

## Context

Задача раунда 2 — разработать интерфейс-дизайн и тезисы, а не боевую
реализацию. Результат — витрина `frontend/showcase-v6.html`
(vite: `http://127.0.0.1:4101/static/v2/showcase-v6.html`, vanilla TS + Vite,
без React). ТЗ раунда: `docs/superpowers/specs/2026-08-29-lnt-redesign-round2-tz.md`.

Протокол продукта сравнивает дельты, а не абсолюты (README), но прежний UI
работал с сессиями поодиночке, а спектрограмма и линейный спектр жили порознь
и не были синхронизированы. Пользовательская приёмка шла по витрине и
последовательно отклонила: каталог без структуры, стопку «график + полоса
спектрограммы» (читалась артефактом) и мёртвую тёмную полосу под графиком
(читалась «пустым местом»).

## Decision

Тезисы, принятые как финальные:

1. **Единица работы — пара сессий**, а не сессия. Полоса пары в шапке называет
   обе сессии ролями «База»/«Сравнение»; легенда графика и каталог говорят теми
   же именами и ролями (чипы А/Б). Ответ пары — дельта `10·lg(Б/А)`, посчитанная
   из самих трасс, а не из `metrics.json`.
2. **Каталог структурирован**: группы по дням, сортировка кликом по колонке
   (доступна с клавиатуры, `aria-sort`), поиск по метке, роли сессий; одна
   плотная строка на сессию. Сортировка по метке распускает группы — одно или
   другое, без вранья.
3. **Сигнальное окно одно, видов два**, переключаются тумблером
   «Спектр | Спектрограмма» в шапке панели. Стопка отвергнута пользователем.
   Дефолт — линейный спектр во всю высоту.
4. **Спектрограмма — вид время×частота** того же окна: шкала секунд слева
   (верх — начало записи), тики частот снизу. Значения и лог-позиции тиков
   захватываются у шкалы спектра — оба вида говорят на одной шкале.
5. **Содержимое спектрограммы: А / Б / Δ Б−А**; по умолчанию — уровень
   сравнения: спокойная дельта вдали от пиков почти чёрная и читается пустым
   полем. Дельта остаётся в один клик и числом в таблице пиков.
6. **Таблица пиков несёт колонку Δ** с направлением-глифом (▲/▼/—): направление
   читается без цвета (ТЗ §6).
7. **Геометрия и типографика ТЗ**: инпут 32px, шапка таблиц 30–32px, цели
   ≥28px, фокус-рамка `outline: 2px solid accent; offset 2px`, кегль UI ≥11px,
   разметка без inline-стилей (динамические позиции — constructed stylesheet),
   данные — Source Code Pro (шаг знака равен JetBrains Mono, колонки не растут).
8. **Полотно спектрограммы рисуется в физических пикселях**
   (буфер = CSS × `devicePixelRatio`), иначе мыло на любом масштабировании.
9. **Под графиком нет мёртвой зоны**: заголовок оси X ушёл в шапку панели
   («Спектр мощности · Гц»), ось сжата до строки тиков (у uPlot дефолт оси X —
   50px плюс `labelSize` 30px, резервируемый даже для пустой подписи).

## Where the decisions live

Для агента, который разрабатывает всё остальное:

- **Эталон дизайна**: `frontend/src/showcase-round2/` — `variantV6.ts/css`
  (сетка, тумблер видов), `catalogV6.ts`, `spectrogramV6.ts` (вид время×частота,
  собственная лог-шкала из `plot.scales.x`), `spectrogramPalette.ts` (шкалы
  heat/delta в цветах трасс §4), `pairbar.ts`, `peaksCompare.ts`,
  `peakMarkers.ts`, `commandbar.ts`.
- **Машиночитаемые контракты дизайна**: `frontend/src/showcase-round2/round2-v6.spec.ts`
  (V6-S1…S20): геометрия и фокус ТЗ, согласованность дельты полотна с таблицей,
  спокойствие дельты вдали от пиков, переключение видов, физические пиксели,
  отсутствие мёртвой зоны. Контракты зелёные на момент приёмки и остаются
  регрессией витрины.
- **Токены и ТЗ**: `frontend/src/showcase-round2/tokens.css`, `DESIGN.md`,
  ТЗ раунда 2 (см. Context).
- **Визуальные артефакты приёмки**:
  `.omo/start-work/evidence/task-redesign-round2/v6-*.png`.
- **Что уже существует в боевом коде, а что дизайн-предложение**: реальная
  спектрограмма продукта — `frontend/src/components/charts/spectrogramView.ts`
  (ECharts-heatmap, тайлы из npz, маркеры, зум). Витринный грам — синтетическая
  canvas-версия для дизайна. При переносе брать тезисы и посадку из витрины,
  а реализацию — из существующих боевых компонентов; не переносить синтетику.
- Витрины V1–V5 — история поиска, не разрабатываются.

## Consequences

- Боевой UI раунда 2 строится по тезисам 1–9; отступление требует нового ADR.
- Витрина V6 заморожена как эталон: правки только с обновлением контрактов
  `round2-v6.spec.ts`.
- Коммиты финала: `c23aec7` (физические пиксели), `a47e12f` (дефолт-уровень),
  `df1187b` (мёртвая зона оси), `18fe267` (два вида одного окна).
- Гейты на момент приёмки: e2e 162/162, vitest 259/259, module-size 4/4,
  build/build:check зелёные; лимит модуля ≤250 чистых строк соблюдён.

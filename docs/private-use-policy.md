# Private-use build policy

This build profile is owner-internal and private. It is built and used only by
the owner, and it is not to be conveyed to another person. Zadig is not bundled,
and the application does not fetch runtime assets.

The optional Hantek integration is pinned to Hantek6022API commit
`e65d52b0f2536e56eaadbb555e5d7b756409c36e`, whose license is GPLv3-or-later.
Any transfer to another person or any public release is outside this private-use
policy and triggers a separate GPL source-and-license compliance decision before
the build may be conveyed. This repository does not claim that the current build
is suitable for public release.

This policy records the project's build and distribution boundary. It is not
legal advice.

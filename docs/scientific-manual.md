# Научный справочник LNT v2

Документ описывает измерительные методики, модель провенанса, статистику
экспериментов, бюджет неопределённости и чтение спектрограмм. LNT не является
сертифицированным средством измерений: все выводы строятся на относительных
сравнениях внутри одной установки.

## Провенанс

Каждая сессия это каталог с неизменяемыми артефактами. Запись атомарна:
каталог `.partial-*` переименовывается в финальный, поэтому сессия на диске
либо целиком, либо отсутствует.

```
<session>/
  manifest.json   # источник, тип, fs, каналы, телеметрия, ch1_setup, truth (для синтетики)
  ch1.npy         # float32, вольты, ВЧ-пробник
  ch2.npy         # float32, вольты, трансформатор 50 Гц (нет при --channels 1)
  metrics.json    # результат анализа schema v2
  spectrum.csv    # сырой scope-plane PSD (frequency_hz, psd_v2_per_hz)
  spectrum_input_referred.csv  # приведённый ко входу PSD, если доступен
```

Манифесты двух схем:

* **schema v1** (legacy и синтетика): без явной модели входа CH1.
* **schema v2** (аппаратный захват): дискриминированное поле `ch1_setup`,
  например `floating_differential_rc_shunt`, `scope_input_terminated` или
  `transformer_line_probe_v1`.

Приведение спектра ко входу описывается машинно-читаемым блоком
`metrics.json.ch1_input_reference`:

| Поле | Смысл |
|---|---|
| `status` | `available` или `unavailable` |
| `reason_code` | причина недоступности, например `manifest_schema_v1` |
| `model_kind` | применённая модель приведения |
| `qualified_bin_count` / `total_bin_count` | сколько частотных бинов прошло квалификацию |
| `provenance.baseline_session_id` | baseline, относительно которого считано превышение |
| `provenance.qualification_rule_id` | правило квалификации бинов |

Синтетические и legacy-сессии всегда дают `status: "unavailable"` с
`reason_code: "manifest_schema_v1"`. Отображаемый `spectrum.csv` остаётся сырым
scope-plane PSD и никогда не выдаётся за приведённые ко входу данные.

Полная цепочка происхождения результата отчёта включает build ID приложения,
версии схем, идентификаторы исходных сессий и экспериментов. Архивы переносят
провенанс вместе с данными (`archive_schema_version`, `provenance`, SHA-256
каждого члена). Контрактные решения зафиксированы в ADR:
[adr/ADR-0001](adr/ADR-0001-canonical-raw-sessions.md),
[adr/ADR-0004](adr/ADR-0004-versioned-analysis-artifacts.md),
[adr/ADR-0007](adr/ADR-0007-identifiers-time-and-units.md).

## Методики измерений

### Базовые правила

* **Не менее 100 циклов сети на запись** (по умолчанию 2.4 с при 50 Гц).
  Короткая запись отклоняется анализом с кодом выхода 2.
* **Per-site baseline.** Перед измерениями в локации снимается self-noise:
  фронтенды отключены, входы терминированы. Это самошум тракта, он вычитается
  из последующих измерений через приведение ко входу.
* **Дельты, не абсолюты.** Калибровочная поправка АЦП не применяется
  (`calibration_used: false` в телеметрии). На дельты внутри одной установки
  она не влияет, поэтому сравнивать нужно `B - A`, а не абсолютные значения.
* **Одинаковая конфигурация пары.** Baseline для приведения совместим только
  с теми же source/rate/range/probe/setup и телеметрией без клиппинга;
  preflight блокирует несовместимую пару.

### Режимы каналов

| Режим | Железо | Синхронизация | Метрики |
|---|---|---|---|
| `2` (дефолт) | CH1 = ВЧ-фронтенд, CH2 = трансформатор 50 Гц | фазовая привязка по восходящим нулям CH2 | все |
| `1` | только CH1 | номинальные окна 20 мс | спектр, пики, μ_pk, σ/μ; P_async/P_sync, f_сети, CV CH2 равны «н/д» |

В одноканальном режиме `ch2.npy` не пишется, `sync_source: "nominal"`.
Сравнение сессий разных режимов возможно: дельты считаются по общим метрикам,
остальные помечаются «н/д».

### Вход CH1 и значения компонентов

Для measurement-сессии вход CH1 описывается RC-моделью
(`floating_differential_rc_shunt`). Номиналы R, C1, C2 задаются флагами
`--rc-r-ohm`, `--rc-c1-nf`, `--rc-c2-nf`; поле
`--component-values-basis` фиксирует происхождение значений: `nominal`
(паспортные) или `operator_measured` (измеренные оператором). Для расчётов
приведения ко входу предпочтительны измеренные значения: паспортный допуск
конденсаторов часто шире, чем вклад самого шума.

### Метрики иголок (line-sync)

CH1 анализируется в полосе 3 кГц до min(3 МГц, 0.45·fs):

* band-спектр Уэлча; пики: частота как центроид полосы выше половинной
  мощности, добротность `Q = f0/FWHM`;
* σ_pk/μ_pk в окне доминирующей фазы: стабильность амплитуды иголок от цикла
  к циклу;
* P_async/P_sync: средняя мощность вне синхронного окна против мощности в нём.

CH2 даёт фазовую привязку (восходящие нули) и CV огибающей вершин 50 Гц.

### Режим качества сети

Один пробник + трансформатор 230:6 превращают LNT в измеритель качества сети.
Анализ пишет секцию `line_quality` вместо needle-метрик: частота сети
(интерполяция пика FFT), RMS фундаментала и полный RMS вторички, THD по
гармоникам H2-H40, таблица гармоник, crest-factor, CV поцикловых пиков.
Значения приводятся к вторичке: реальное сетевое напряжение примерно равно
вторичка × (230 / U_xx), где U_xx это напряжение холостого хода вашего
трансформатора (для типового 2 ВА 230:6 около 10 В, то есть множитель
21-23). A/B-сравнение для line-quality сессий не поддерживается.

## Статистика экспериментов

Эксперимент группирует серии повторов вокруг одного вопроса. Протокол
объявляется до расчёта, и таблица допустимых переходов протокол → оценка
закрыта:

| Протокол | Допустимые оценки |
|---|---|
| AB | paired difference |
| ABA | qualified within-run contrast |
| repeated blocks | block paired |
| cohort | descriptive only |
| longitudinal | descriptive only |

Запрос неразрешённой оценки отклоняется с кодом причины, а не «угадывается».

Практические правила:

* Члены эксперимента проходят QC до расчёта (клиппинг, короткая запись,
  несовместимый baseline); отбраковка члена фиксируется в протоколе.
* ABA-контраст отдельно квалифицирует дрейф точки A между прогонами: если
  дрейф сопоставим с эффектом, расчёт отказывает, а не выдаёт число.
* Тренды (`lnt experiment trends`) показывают движение величины по времени;
  гипотезы (`lnt hypothesis add/edit/status`) формулируются до расчёта и
  остаются аудируемыми: статусная машина запрещает тихие правки задним числом.

## Неопределённость

Бюджет неопределённости строится из двух источников.

**Type A**: повторяемость, оценённая из самих повторов серии (стандартное
отклонение среднего).

**Type B**: явные компоненты с заявленным распределением: прямоугольным,
треугольным или нормальным. Каждый компонент несёт величину, единицы и
чувствительность к измеряемой величине; ковариации задаются отдельными
членами бюджета.

Распространение линейное: суммируются квадраты вкладов с учётом
ковариационных членов, результат это комбинированная стандартная
неопределённость. Расширенная неопределённость использует коэффициент охвата
k = 2 по умолчанию. Итог отчёта всегда сопровождается составом бюджета, чтобы
любой вклад можно было оспорить и пересчитать.

Чего бюджет не делает: он не заменяет поверку и не переносится на другие
установки. Компоненты Type B действительны только для той аппаратной
конфигурации, для которой они заявлены.

## Спектрограммы

Спектрограмма строится потоковым STFT поверх сырых отсчётов CH1. Обзор
агрегирует мощность в ограниченную сетку log-частотных полос и временных
бинов (верхние границы фиксированы моделями артефакта), зум пересчитывает STFT
на выбранном окне без обращения к исходному файлу целиком.

Как читать:

* **Горизонтальные полосы** это стационарные компоненты (частоты импульсного
  блока питания, гармоники сети). Их уровень удобно сравнивать между сессиями
  по спектру Уэлча.
* **Вертикальные штрихи** это широкополосные события, синхронные по времени:
  щелчки реле, коммутация нагрузки, запуск двигателя. Они видны в списке
  событий инспекции.
* **Игольчатая структура, привязанная к фазе сети**, проявляется как
  периодическая по времени сеть тонких линий с периодом 10 мс (полупериод
  50 Гц). Мерой её служат σ_pk/μ_pk и P_async/P_sync, а не визуальная оценка.
* **Шум пола** между событиями это шум тракта; сравнивать его уровень имеет
  смысл только после вычитания self-noise baseline той же локации.

Децимация при отображении (min/max) сохраняет экстремумы бинов и не меняет
статистику: все числа считаются по полным данным, ограничения касаются только
рисования.

## Ограничения интерпретации

* Абсолютные уровни PSD корректны в пределах одной конфигурации входа и
  диапазона; межустановочные сравнения требуют собственного baseline.
* Одноканальный режим теряет фазовую привязку, поэтому P_async/P_sync в нём
  принципиально «н/д», а не «нуль».
* THD в line-quality режиме считается по вторичке трансформатора; частотные
  свойства трансформатора ограничивают верхние гармоники.
* Отчёты фиксируют QC-решения и провенанс, но не делают выводов за
  оператора: интерпретация остаётся за человеком.

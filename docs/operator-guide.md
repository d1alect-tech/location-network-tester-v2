# Руководство оператора LNT v2

Сборка для личного пользования (private-use). Пакет не является установщиком
и не предназначен для передачи другим людям. Условия описаны в
[packaging-notices.md](packaging-notices.md) и [private-use-policy.md](private-use-policy.md).

## Состав поставки

Поставка разворачивается из ZIP-архива вида `LNT-0.1.0-win64-private-use.zip`.
Внутри одного каталога:

```
LNT/
  LNT.exe                  запуск приложения
  PRIVATE-USE.txt          метка сборки: owner-internal, no conveyance
  private-use-policy.md    политика использования
  THIRD_PARTY_NOTICES.md   уведомления третьих сторон
  dependency-manifest.json версии зависимостей сборки
  licenses/                тексты лицензий компонентов
  _internal/               среда выполнения и код приложения
```

Python и Node на машине не нужны: среда выполнения лежит внутри `_internal`.
Zadig в пакет не входит, драйвер WinUSB ставится отдельно (см. ниже).

### Установка

1. Распакуйте ZIP в любой каталог на локальном диске. Путь может содержать
   кириллицу, но без сетевых дисков: приложение работает только с локальными
   путями.
2. Прочитайте `PRIVATE-USE.txt` и `private-use-policy.md`.
3. Запускайте `LNT.exe`. «Установка» в классическом смысле нет: удалить
   приложение можно простым удалением каталога.

Данные приложения живут вне каталога программы:

| Назначение | Путь |
|---|---|
| Корень сессий по умолчанию | `%USERPROFILE%\lnt-sessions` |
| Конфигурация | `%APPDATA%\LNT\config.json` |
| Каталог БД (проекции) | `%LOCALAPPDATA%\LNT\catalog.sqlite3` |
| Журнал работы | `%LOCALAPPDATA%\LNT\logs` |

## Первый запуск

`LNT.exe` поднимает локальный сервер и открывает браузер сам.

* Сервер слушает только `127.0.0.1`, предпочтительный порт `8765`; если порт
  занят, берётся следующий свободный.
* Второй запуск видит работающий экземпляр, не поднимает второй сервер и просто
  открывает его адрес в браузере.
* Останов: закрыть окно консоли или `Ctrl+C`. Аварийное завершение пишет код
  поддержки в журнал и одну строку в stderr.

Приложение полностью офлайн. Внешние сетевые запросы отсутствуют: графики,
шрифты и интерфейс вендорены внутрь пакета. Это свойство проверяется тестами
сборки.

## Подготовка железа (один раз)

Осциллограф Hantek DSO-6022BE требует драйвера WinUSB. Драйвер и утилита Zadig
в пакет не входят и распространяются отдельно; шаги описаны в документации
исходного проекта.

1. Подключите осциллограф по USB.
2. Установите WinUSB для VID устройства через Zadig (загрузочный VID `04B4`,
   рабочий VID `04B5`).
3. Проверьте готовность кнопкой «Проверить устройство» на экране «Захват» или
   командой диагностики. Приложение само назовёт, какое звено цепочки
   backend → USB → прошивка не готово и что делать (см.
   [safety-and-recovery.md](safety-and-recovery.md)).

RAM-прошивка загружается только явной операцией захвата; диагностика её не
трогает.

## Офлайн-рабочий процесс

Научный цикл LNT: **Подготовка → Захват → Инспекция → Сравнение/Эксперимент →
Объяснение/Экспорт**. Каждый шаг соответствует экрану интерфейса.

### 1. Подготовка (`#/prepare`)

Экран «Подготовка»: профили измерений, контекст сессии (место, схема, метки)
и обслуживание каталога. Здесь же создаётся baseline самошума для локации:
захват с включённым режимом self-noise, фронтенды отключены, входы
терминированы. Baseline снимается заново при смене места измерений.

### 2. Захват (`#/capture`)

Экран «Захват»: длительность, частота, диапазон CH1, режим каналов, метка,
число повторов серии. Перед стартом выполняется preflight: он блокирует захват
при неготовом устройстве, нехватке места на диске, несоответствии типа сессии
модели входа и предупреждает о вероятном клиппинге или слабом сигнале. Preflight
никогда не меняет настройки сам.

Типовые сценарии:

```powershell
# измерение помех: CH1 = RC-вход, CH2 = трансформатор 50 Гц
lnt capture D:\ses\after-upgrade --label "после" --repeat 5 --interval 30

# baseline самошума локации
lnt capture D:\ses\noise-baseline --self-noise

# качество сети: один пробник + трансформатор 230:6
lnt capture D:\ses\line-quality --line-quality --probe-multiplier 10 --range 5.0
```

Без железа тот же путь проверяется синтетикой:

```powershell
lnt simulate D:\ses\sim-quiet --profile quiet --label "проверка тракта"
```

### 3. Инспекция (`#/inspect`)

Экран «Инспекция»: манифест, метрики, спектр, спектрограмма и события сессии.
После каждой записи анализ запускается автоматически; для старых сессий есть
команда `lnt analyze <каталог>`. Графики строятся из сырых артефактов сессии,
данные при отображении не искажаются (применяется только min/max-децимация
для скорости отрисовки).

### 4. Сравнение и эксперименты (`#/experiments`)

Правило интерпретации одно: сравнивать дельты, а не абсолюты. Базовая точка A,
измерение после изменения B, дельта считается как `B - A`.

```powershell
lnt compare D:\ses\noise-baseline D:\ses\after-upgrade
```

Для статистики серия повторов оформляется в эксперимент с протоколом (AB,
ABA, повторные блоки, когорта, лонгитюд). Экран «Эксперименты» ведёт протокол,
QC-решения по членам и расчёт величины; гипотезы фиксируются до расчётов и
аудируются. Подробнее: [scientific-manual.md](scientific-manual.md).

### 5. Объяснение и экспорт (`#/reports`)

Экран «Отчёты» собирает научный отчёт schema 1: провенанс, QC-статус членов,
расчёт величины, бюджет неопределённости и ссылки на гипотезы. Экспорт
выполняется в JSON, CSV-таблицы и офлайн HTML. Архив явной выборки сессий
и экспериментов делается командой `lnt archive create` (проверка целостности
по SHA-256, см. [safety-and-recovery.md](safety-and-recovery.md)).

### Настройки и каталог

* Экран «Каталог»: поиск, фильтры по health/типу/меткам, инспектор контекста,
  управление профилями и сохранённые представления.
* Экран «Настройки»: тема, корень сессий, поведение задач. Одновременно
  выполняется одна задача; вторая попытка получает отказ `409`, отмена серии
  происходит после текущей сессии.

## Краткая справка CLI

| Команда | Назначение |
|---|---|
| `lnt ui` | веб-панель (localhost) |
| `lnt capture <каталог>` | захват с осциллографа |
| `lnt simulate <каталог>` | синтетическая сессия по профилю |
| `lnt analyze <каталог>` | анализ: metrics.json + spectrum.csv |
| `lnt compare A B` | таблица дельт двух сессий |
| `lnt experiment create/stats/trends/check/confirm` | эксперименты и расчёты |
| `lnt hypothesis add/edit/status` | аудируемые гипотезы |
| `lnt archive create/list/verify/restore` | экспорт, backup и restore |
| `lnt catalog status/reindex/verify` | обслуживание каталога |
| `lnt support-bundle out.zip` | диагностика для поддержки без секретов |
| `lnt selftest` | самопроверка пайплайна без железа |

Коды выхода: `0` успех; `2` некорректный вход или данные; `3` устройство
недоступно; `1` провал selftest. Ошибка печатается одной строкой в stderr,
без traceback. Полная таксономия ошибок и восстановление:
[safety-and-recovery.md](safety-and-recovery.md).

## Ограничения

* Сборка для личного пользования: передача другим лицам и публикация запрещены
  политикой ([packaging-notices.md](packaging-notices.md)).
* LNT не является сертифицированным средством измерений; результаты служат
  для относительных сравнений в рамках одной установки.
* Переносимость на чистую машину без драйвера WinUSB не заявляется: подготовка
  железа остаётся обязательной.

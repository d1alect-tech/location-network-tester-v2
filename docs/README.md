# Документация LNT

Указатель документов репозитория, сгруппированный по задачам читателя.
Операторские документы на русском, ADR и процессные документы на английском.
Команды выполняются в PowerShell из корня репозитория, каждая команда LNT
запускается в форме `uv run --python 3.12 lnt ...`.

## Начало работы

- [README проекта](../README.md): что такое LNT, быстрый старт без железа.
- [Установка LNT на Windows](install-ru.md): установка из исходников через uv, extras, драйвер Hantek, первый запуск, обновление и удаление.
- [Руководство оператора LNT v2](operator-guide.md): установка переносной сборки, первый запуск, подготовка Hantek, рабочий процесс по экранам.
- [Настройка LNT силами агента](agent-setup.md): пошаговый сценарий установки переносной сборки ИИ-агентом, smoke-проверки и коды выхода.

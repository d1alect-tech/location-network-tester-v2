## 2. Решение: M1 «Гибрид»

Интеракшн-контракт M1 — синтез консультации ultrabrain и рекомендации architect
(логика состояний уже верна в коде: `pick()`/`assignSlot()` в `pairState.ts`
давно реализуют нужную семантику, UI её просто не показывал; правится
презентация). Решения оркестратора по расхождениям консультантов:

1. **Арм-жест удалён из UI.** Клик по слоту pairbar больше не вводит скрытый
   режим arm (источник жалобы — двухшаговый жест, о котором владелец не знал).
   Слот-клик теперь `onSlotTap`: фокус рейла + пульс кнопок «А» через
   transient-атрибут `[data-pulse]` (снимается по animationend; под
   `prefers-reduced-motion` пульса нет). Слот-клик пару не мутирует.
   API `arm()`/`setArmed` в pairbarV6 остаются dormant — вызываются только
   тестами напрямую, из продукта не используются.
2. **Рейл и кнопки живы во время job-busy.** Залочен только pairbar (как
   раньше); строки и кнопки «А»/«Б» кликабельны mid-flight — пины
   `w1Chrome.spec.ts:585/605` живы без правок.

## 3. Механика M1 (как реализовано)

- Кнопки «А»/«Б» в roleCell каждой строки каталога: `data-assign="a|b"`,
  `tabindex="-1"` (фокус-навигация — по строкам, клавишей — KeyA/KeyB),
  `aria-label` «Сделать базой» / «Сделать сравнение», `aria-pressed` явный на
  занятых строках; `title` = loadKey — имя каталога для дублей (различает
  три сессии syn-quiet-seed6022). `stopPropagation` — клик кнопки не
  проваливается в pick.
- Тело строки = `pick()`: клик = «сравнить с базой» (не в паре → B, либо A
  если A пуст; строка уже в паре → честный no-op).
- `KeyA`/`KeyB` по `event.code` (физические клавиши, layout-independent) на
  сфокусированной строке; в поисковом инпуте игнорируются.
- Эхо-статус строки: `tr[data-in-pair="a|b"]` — кромка 2px + слабый тинт
  (цвета чипов А/Б), без hover.
- `pairState.ts` НЕ ТРОНУТ (запрещено обоими консультантами): `pick()/
  assignSlot()` уже реализовали контракт, правка чисто презентационная —
  diff по файлу пуст (подтверждено аудитом).
- Подсказка: «Выбор в каталоге: клик по строке — сравнение; кнопки А/Б —
  точное назначение.»

## 12. Строка 13 (F3-remedy): формат метки/типа/даты в рейле

Дефект живой QA владельца (F3): «Мне не нравится формат отображения метки,
типа и даты в инспекции, в левом столбце выбора сессий/записей». Гейт
вариантов на живом пикере (`frontend/prototypes/catalog-row-format.html`,
клавиши 1/2/3): победитель — V1 «Мета под меткой» (двухстрочная строка).
Обязательный инвариант владельца: «когда обрезаются какие-либо данные или
не лезут друг на друга» — недопустимо; усечение многоточием запрещено,
полный текст виден в покое.

Реализация (RED→GREEN, `catalogRowFormat.{test,spec}.ts`):
- строка сессии — одна `td[colspan=4]` с контуром `.cat-row`:
  линия 1 — зона А/Б (`.cat-assign-wrap`, flex:none) + чип роли + метка
  (`flex:1 + min-width:0 + overflow-wrap:anywhere` — полный перенос,
  высота строки вариативная); линия 2 — `.cat-meta` (flex-wrap):
  локализованный тип · health-пилюля · analyzed-пилюля · время (группы по
  дате — ЧЧ:ММ; сортировка по метке — «дд.ММ.гггг, ЧЧ:ММ» строкой из
  UTC-литерала, без Date/Intl — сдвиг зоны).
- Заголовки дней с годом: «5 октября 2026 г.» (ru-RU, year:numeric).
- Типы: `SESSION_TYPE_LABELS` + measurement→«Измерение»,
  self_noise→«Самошум» (реальный перечислитель бэкенда; capture/simulate —
  мок-диалект; cm_dm/cm_dm_calibration остаются raw-passthrough до
  глоссарного решения владельца).
- Сортировка: thead удалён (строки односоставные — заголовки 4-колоночной
  таблицы больше не соответствуют строкам), кнопки `.cat-sort` живут в
  `.cat-tools` второй строкой (`.cat-sortbar`); атрибуты
  `data-cat-sort`/aria-sort сохранены — клик-пины живы.
- Сплит: `catalogRowMarkup.{ts,css}` (билдеры строки + scoped CSS);
  `catalogColumnHealth.css` удалён (пилюли в мета-строке);
  `catalogAssign.el` обёртка получила класс `.cat-assign-wrap`.
- v6.css только уменьшился: мёртвые правила 4-колоночной таблицы
  (ширины колонок, is-flat, .cat-label-cell, .cat-role-noise, .cat-th)
  удалены; `tbody td` без фиксированной высоты.

Отклонённые альтернативы (консультация визуального дизайна, измерено в
Chrome на 336px): `-webkit-line-clamp:2`+title — многоточие на границе
clamp = прямое нарушение инварианта; expand-on-hover — метка скрыта в
покое, hover отсутствует на тач, высота прыгает под курсором.

# Глоссарий LNT

Термины планирования и трекинга. Только язык, без деталей реализации.

- **Очередь** — упорядоченный список пунктов работ в `docs/roadmap.md`; канонический носитель «что делаем дальше» (очереди A, B, C, D).
- **Волна** — единица исполнения очереди, трекается одним GitHub-issue («трекер волны»); скоуп волны задаёт владелец.
- **Слот волны** — заранее созданный пустой трекер волны без скоупа. C-слоты (C0–C3) — core: бэкенд, наука, данные. U-слоты (U1–U4) — интерфейс и UX.
- **Витрина (showcase)** — прототип интерфейса для реакции владельца; живёт в отдельном каталоге `frontend/src/showcase-*`, победитель едет в продукт, каталог замораживается.
- **Карта (wayfinder)** — issue с лейблом `wayfinder:map`; индекс решений усилия, тикеты-решения — его дочерние issues.
- **Функциональная очередь** — ветка очереди D с функциональными пунктами короткого цикла (баги, CLI↔UI-паритет, леджер).
- **Интерфейсная волна** — ветка очереди D: новый визуальный язык через витрины, свой темп, длиннее функциональной.
- **Пара A/B** — две сессии под сравнением в инспекции; дельта считается как `B − A`. Сигнатурный объект интерфейсной волны.
- **Сессия** — атомарный каталог записи на диске: `manifest.json` + каналы + артефакты анализа. Идентичность — `session_id` из манифеста; имя каталога может расходиться (известный дефект поиска).
